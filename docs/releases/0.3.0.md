# azdocs v0.3.0: A clearer view of your estate

This release refreshes the desktop around a denser dashboard and a dedicated
Regions explorer. Collection progress now brings website previews into the
same panel, and snapshot outcomes distinguish missing audit evidence from
incomplete inventory.

## Highlights

- **Refreshed desktop.** A navy navigation frame, Inter typography and
  consistent light and dark styling keep the workspace focused on estate
  data. Overview combines the static location map with resource history;
  selectable snapshots and spaced markers make nearby collections easier
  to inspect.
- **Regions explorer.** Explore Azure regions on an interactive world map,
  inspect resource counts and region metadata, and use zoom controls to
  investigate nearby locations. Overlapping hit areas resolve to the nearest
  marker.
- **Clearer collection outcomes.** A new `warnings` status means inventory
  finished but one or more finding checks could not complete. Missing
  inventory still produces a partial snapshot. Query errors and provenance
  remain available, and failed checks are never counted as passes.
- **Inline website previews.** Native website capture renders in an isolated
  child view and sends image previews to the collection panel, without
  opening another window. Progress, permission results and collection
  options share the same surface.
- **Query fixes.** The unused managed identity check uses a supported Resource
  Graph join, nested API diagnostics are preserved, and dropped inventory
  rows correctly mark the snapshot partial.

## Upgrade notes

Scripts that enumerate snapshot statuses should accept `warnings` alongside
the existing values. `latest` and history include these snapshots;
`--fail-on partial` continues to exit non-zero for warnings. Existing snapshots
keep their recorded status.

Windows installers are signed only when Trusted Signing is configured for
the release; otherwise SmartScreen warns on first run. See the
[installation guide](https://github.com/russmckendrick/azdocs/blob/main/docs/usage/installation.md#windows-smartscreen).

## Install or upgrade

Upgrade the command-line application with Homebrew:

```sh
brew upgrade russmckendrick/tap/azdocs
```

On Apple Silicon macOS, upgrade the signed and notarized desktop app with:

```sh
brew upgrade --cask russmckendrick/tap/azdocs-desktop
```

Portable CLI archives and desktop installers for macOS, Windows and Linux are
attached to this release, each with an SBOM or a build-provenance
attestation. Verify direct downloads against `azdocs-checksums.sha256` or
with `gh attestation verify <file> --repo russmckendrick/azdocs`.
