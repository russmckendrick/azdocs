# azdocs v0.4.1: Signed on Windows

A packaging release. The Windows downloads are now code-signed, so Windows
names a publisher instead of warning about an unknown one. Nothing else
changes; reports, exports and the desktop app behave exactly as in v0.4.0.

## Highlights

- **Signed Windows binaries.** The desktop setup executable, the MSI, the
  desktop app itself, its uninstaller and the CLI's `azdocs.exe` are all
  signed and timestamped with a Certum Open Source code-signing certificate
  issued to **Open Source Developer Russell McKendrick**.

## Upgrade notes

SmartScreen reputation builds per file as a release is downloaded, so for the
first days after a release Windows may still show **Windows protected your
PC**, now naming the publisher. Choose **More info › Run anyway** after
verifying the download. See the
[installation guide](https://github.com/russmckendrick/azdocs/blob/main/docs/usage/installation.md#windows-smartscreen).

## Install or upgrade

Upgrade the command-line application with Homebrew:

```sh
brew upgrade russmckendrick/tap/azdocs
```

On Apple Silicon macOS, upgrade the signed and notarized desktop app with:

```sh
brew upgrade --cask russmckendrick/tap/azdocs-desktop
```

Portable CLI archives and desktop installers for macOS, Windows and Linux are
attached to this release, each with an SBOM or a build-provenance
attestation. Verify direct downloads against `azdocs-checksums.sha256` or
with `gh attestation verify <file> --repo russmckendrick/azdocs`.
