# azdocs v0.4.0: Reports that match the desktop

This release carries the desktop's design into the exported documents. A new
Azure theme is the default for PDF, Word and HTML, the reports and the draw.io
workbook gain a world map of resource locations, and the desktop merges Estate
and Inventory into one place to explore resources and their query results.

## Highlights

- **Azure document theme.** The desktop's navy frame and Azure blue in print:
  a gradient cover, banded tables, card stats and the desktop's severity,
  service-family and map colours. Field Report remains available and gains a
  warm paper-gradient cover. Pick either from the new Document style control
  on the desktop Exports page, which previews each theme's cover and a body
  page.
- **Themes own their artwork.** Cover backgrounds are A4 SVGs named by
  `layout.cover_background` and filled from the theme palette; chart bars,
  service-family series and the world map take their colours from the theme
  too. Custom themes that set none of these keep their previous look.
- **World maps in print and draw.io.** The Regional concentration section of
  the PDF and Word reports opens with a resource-locations map, and the draw.io
  workbook gains a Regions sheet with editable, non-overlapping labels.
- **Estate and Inventory together.** Filter Estate to a resource type to see
  its inventory query columns, with child rows under their parent; every
  resource record lists the query rows that name it. VM and Arc machines now
  list their extensions.
- **Desktop polish.** Overview KPI tiles show movement since the previous
  snapshot, crowded map markers spread apart with leader lines, and Exports
  and Settings share the ledger layout of the other views.

## Upgrade notes

Azure is now the default document theme. To keep the previous look, set
`theme = "field-report"` under `[branding]` or choose Field Report on the
Exports page.

Windows installers are signed only when Trusted Signing is configured for
the release; otherwise SmartScreen warns on first run. See the
[installation guide](https://github.com/russmckendrick/azdocs/blob/main/docs/usage/installation.md#windows-smartscreen).

## Install or upgrade

Upgrade the command-line application with Homebrew:

```sh
brew upgrade russmckendrick/tap/azdocs
```

On Apple Silicon macOS, upgrade the signed and notarized desktop app with:

```sh
brew upgrade --cask russmckendrick/tap/azdocs-desktop
```

Portable CLI archives and desktop installers for macOS, Windows and Linux are
attached to this release, each with an SBOM or a build-provenance
attestation. Verify direct downloads against `azdocs-checksums.sha256` or
with `gh attestation verify <file> --repo russmckendrick/azdocs`.
